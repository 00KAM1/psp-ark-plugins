# Checkpoint source

Save-data history for PSP games on ARK-5. User manual: [../docs/checkpoint.md](../docs/checkpoint.md). Internals: [../docs/sidequest-checkpoint-how-it-works.md](../docs/sidequest-checkpoint-how-it-works.md).

```
export PSPDEV=/path/to/pspdev PATH=$PSPDEV/bin:$PATH
make                    # gives checkpoint.prx
sh tests/run_tests.sh   # PC tests; needs gcc
```

| File | Purpose |
|---|---|
| `src/main.c` | Start-up |
| `src/hook.c` | Notices saves, queues folders |
| `src/vault.c` | Copies, history limits, restore, pins (tested on a PC) |
| `src/journey.c` | The journey log's file, text wrapping and paging (tested on a PC) |
| `src/jtext.c`, `src/jfont_data.c` | UTF-8 reading and the 8x8 Japanese glyph table (generated by `tools/make_jfont.py`) |
| `src/ui.c` | Menu, quit screen, hand-over to Sidequest |
| `src/blit.c`, `src/util.c` | Drawing, log, config |

Internal names use the prefix `BT_` from the plugin's working title.
